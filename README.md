# Data Centre Predictive Maintenance & AI Operations Intelligence

## Phase 1 — Data Generation
Synthetic infrastructure-monitoring data for servers, designed for:
Anomaly Detection → Time-Series Analysis → Failure Prediction → Claude AI → Power BI.

## Run
1. Create a Python 3.13 virtual environment.
2. `pip install -r requirements.txt`
3. `python generate_data.py`

Output:
`data/raw/data_centre_sensor_data.csv`

The dataset is synthetic/demo data and should not be presented as real production measurements.
